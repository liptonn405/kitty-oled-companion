Рабочее пространство для эмулятора терминала Kitty с анимированным компаньоном, информационной панелью и оформлением в стиле Gruvbox.

Проект превращает стандартный терминал в полноценную рабочую среду. В отдельной панели отображаются живые OLED-глаза персонажа, который реагирует на ваши действия в командной строке, работу с Git и общую активность в системе.

## Возможности и компоненты

* **Анимированный компаньон (`robot_eyes.py`, `robot_stage.py`)**: рендеринг глаз в реальном времени с плавной физикой движений (`robot_physics.py`) и сохранением состояния (`robot_memory.py`).
* **Реакция на действия (`robot_git.py`, `robot_activity_v3.py`, `robot_hooks.bash`)**: персонаж отслеживает выполнение команд в терминале, переключение веток, коммиты и загрузку системы через внутреннюю шину событий (`robot_bus.py`).
* **Информационная панель (`panel.py`)**: боковой виджет для вывода системных метрик и статуса окружения.
* **Готовая сессия и оформление (`kitty.conf`, `desktop.session`, `dark_blur.py`, `fastfetch.jsonc`)**: настроенная раскладка окон Kitty, цветовая схема, размытие фона и компактный вывод информации о системе при запуске.

## Структура репозитория

* `launch.sh` — основной скрипт для запуска настроенной сессии Kitty со всеми панелями.
* `kitty.conf` — конфигурационный файл терминала (шрифты, цвета, отступы, управление).
* `desktop.session` — файл сессии, описывающий расположение и размеры окон при старте.
* `robot_eyes.py` — модуль отрисовки и анимации глаз компаньона.
* `robot_stage.py` — управление сценой и состояниями персонажа.
* `robot_physics.py` — расчет инерции, взгляда и плавных переходов.
* `robot_bus.py` — шина обмена событиями между терминалом и скриптами робота.
* `robot_git.py` — отслеживание состояния Git-репозиториев.
* `robot_memory.py` — хранение настроек и памяти компаньона между сессиями.
* `robot_activity_v3.py` — актуальный модуль анализа активности пользователя.
* `robot_hooks.bash` — перехватчики команд для оболочки Bash.
* `work.bashrc` — дополнительный профиль окружения для рабочих вкладок.
* `panel.py` — скрипт информационной панели.
* `fastfetch.jsonc` — конфигурация утилиты fastfetch.

## Как установить и подключить себе

### 1. Установка зависимостей

Для работы потребуется установленный эмулятор терминала Kitty, Python 3 и утилита fastfetch.

Для Arch Linux:
```bash
sudo pacman -S kitty python fastfetch
```

Для Debian / Ubuntu:
```bash
sudo apt update && sudo apt install kitty python3 fastfetch
```

*(Примечание: если в скриптах используются сторонние Python-библиотеки, например `psutil`, установите их через `pip install psutil` или системный менеджер пакетов).*

### 2. Клонирование репозитория

Рекомендуется склонировать проект в директорию конфигураций Kitty, чтобы все относительные пути работали корректно:

```bash
git clone https://github.com ~/.config/kitty/gruvbox-desktop
cd ~/.config/kitty/gruvbox-desktop
```

### 3. Подключение к вашей системе

1. Выдайте права на выполнение скрипту запуска:
   ```bash
   chmod +x launch.sh
   ```

2. Чтобы компаньон реагировал на ваши команды в терминале и события Git, подключите файл хуков в ваш основной конфиг Bash (`~/.bashrc`):
   ```bash
   echo "source ~/.config/kitty/gruvbox-desktop/robot_hooks.bash" >> ~/.bashrc
   source ~/.bashrc
   ```

3. При необходимости поправьте пути к скриптам внутри `desktop.session` и `launch.sh`, если вы склонировали репозиторий в другую папку (например, в `~/code/kitty-oled-companion`).

### 4. Запуск

Запустите готовое рабочее пространство командой:
```bash
~/.config/kitty/gruvbox-desktop/launch.sh
```

Для удобства можно создать алиас в `~/.bashrc`, чтобы запускать окружение одним словом:
```bash
echo "alias kdesk='~/.config/kitty/gruvbox-desktop/launch.sh'" >> ~/.bashrc
```

## Настройка

* Параметры шрифтов, прозрачности и горячих клавиш изменяются в файле `kitty.conf`.
* Пропорции окон и расположение панели с глазами настраиваются в `desktop.session`.
* Поведение персонажа, тайминги моргания и реакции на команды можно изменить в `robot_eyes.py` и `robot_activity_v3.py`.
